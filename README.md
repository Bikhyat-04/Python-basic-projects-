## 📁 Projects

### Calculator (`calculator.py`)
A command-line calculator that performs basic arithmetic operations.
- Addition, subtraction, multiplication, division
- Handles division by zero gracefully

###  Dice Roll Game (`dice_roll_game.py`)
Simulates rolling one or more dice.
- Random number generation
- Supports multiple dice rolls

###  Number Guessing Game (`number_guessing_game.py`)
A classic guessing game where the player tries to guess a randomly generated number.
- Provides "too high" / "too low" hints
- Tracks number of attempts

###  QR Code Generator (`qrcodegenerator.py`)
Generates QR codes from any text or URL input.
- Saves QR codes as image files
- Uses the `qrcode` library

###  Rock Paper Scissors (`rock_paper_scissor.py`)
Play Rock, Paper, Scissors against the computer.
- Randomized computer moves
- Win/loss/draw detection

##  Getting Started

### Prerequisites
- Python 3.x

### Installation

```bash
git clone https://github.com/Bikhyat-04/Python-basic-projects-.git
cd Python-basic-projects-
```
### Running a Project

```bash
python calculator.py
python dice_roll_game.py
python number_guessing_game.py
python qrcodegenerator.py
python rock_paper_scissor.py
```
